Gate 2, step 2 of 2

Built on the approved low-fi wireframe (SCR-07v2-lofi_v1.html, approved 2026-11-17) and the approved SCR-07 v1 hi-fi with its G3 differences, using only design system v1 tokens and components. Open as SCR-07v2_v1.html#light to start in light.

Decisions made in this step, for review
  • Pause is a small secondary button with the pause icon; Resume a small primary button with the play icon, because it is the decision a paused job waits for; Cancel keeps the danger style. "Start again with 128" is a secondary button with the refresh icon.
  • Paused uses the paused state colour (amber) and the pause icon; stalled the stalled colour (pink) and the hourglass, as on SCR-04 v2.
  • "Now / outcome" keeps v1's rule: the error colour only for a failure's code, the running colour only for the progress bar; reasons are secondary text, with the key figure (79 °C, 5 min 12 s) in primary text.
  • Denser table cells (8 px sides instead of 12), so a row with Pause and Cancel fits at 1280 px; SCR-02 got the same at its G3.
  • No new icons; pause, play and hourglass are in the set the app already uses.
  • The contrast rules approved since v1 (light state text and badges, dark pills on a selected row) are applied, so the mockup matches the built app.

Accessibility notes for implementation

  • Each row action's name includes its job ("Pause job_0031"); at 1024 px the icon-only buttons keep it as their accessible name and tooltip.
  • Pausing is announced once ("job_0031 paused"), as other state changes are; the toast is role="status".
  • Paused and stalled never rest on colour: each pill has its icon and word.
