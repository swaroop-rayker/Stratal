Decisions made in this step, for review
  • The comparison page uses SCR-11's page header and cards, breadcrumb Models › Compare, with Add or remove versions… and a ghost Copy link at the right.
  • Versions are table columns headed by the version ID in mono and the lineage name in secondary text, with a vertical rule between columns so each version reads as one column.
  • The best figure is semibold with the accent best badge, SCR-10's badge for the best trial. Tied figures share it; when every version ties, no badge is shown. Accuracy's count ("17 of 18") and its Wilson interval sit beside and below it in secondary text.
  • The interval chart is categorical 1, as SCR-10 and the task metrics use for one series: a dot with whiskers per version on quarter gridlines, the figure at the right, and a Table view. Versions are told apart by their row labels, not by colour.
  • The overlap sentence is an info callout (SCR-09 v2's callout), because it explains rather than warns.
  • F1 by class is the dense table with categorical 1 mini bars beside each figure, sorted by spread, with the best marked as in the metrics table.
  • The picker is a 560 px drawer from the right, like the version drawer: native checkboxes in accent, versions grouped under their lineage with its ID, rows without test metrics in secondary text with the reason, Score on test as a small button with the play icon, and a scoring row as a running pill with its job. The footer counts the choice and holds Compare N.
  • Try it stays in the lineage page's right-hand card. A table record is two fields a row, labelled by column name in mono (cut with an ellipsis, the full name on hover), an empty field showing "empty: imputed" in italics. The answer is categorical 1 bars with the probability. The row's true label is an info callout with a check or a cross and the words "matches" or "differs", never colour alone.
  • The parent across lineages is a row in the version drawer with the lineage name and a neutral another lineage badge; Fine-tuned into lists the children. A lineage founded by a fine-tune shows an info callout with the branch icon under its title. Fine-tune… uses the branch icon among the drawer's actions.
  • Design-system addition, for approval: in dark, an accent badge (computed once, best) inside a selected or hovered table row mixes its text 70 % toward text-primary, as pills already do there (approved at an earlier Gate 3). It measured 4.31:1 on the selected row's accent tint; with the rule it passes. AA in both themes: 587 text elements each.

Accessibility notes for implementation

  • The metrics and F1 tables have captions and real column headers (the version IDs); "best" is a word in the cell, so neither weight nor colour carries it alone.
  • The interval chart is an image with a full text label, and Table swaps it for a table of version, accuracy, low and high.
  • The picker's checkboxes are named by version; a disabled one's name says why. Score on test announces the queued job.
  • Try it's fields are labelled by column name (the full name also as the title when cut); a refused field gets aria-invalid and its message as the description.
