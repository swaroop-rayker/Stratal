Layout and hierarchy only, inside the approved shell (faint). Blue numbers are annotations. The data: the Small CNN from SCR-08 on the CIFAR-10 split ds_f8e67211dd94 (288,746 parameters). The memory figures are the builder's estimate (ADR-0017 rule 7); on the card the same CNN measured 0.23 GB at batch 128 and 0.79 GB at 512 (M8, NFR-1), so the estimate errs on the safe side.

Layout decisions to review

  1. One page in the order you decide things: model, data, training settings, device, then start. A right-hand column stays in view with the VRAM check, what will happen, and Start run.
  2. The model comes from SCR-08 (or a template, or Train again on SCR-11). The page shows its name, family, parameters and memory, with Edit in builder. Reached with no model, it says so and links to SCR-08 and the templates.
  3. The training form is generated from GET /config/schemas/train (UI-2.3), grouped into schedule, optimizer, reproducibility and checkpoints. momentum appears only for SGD. The checkpoint interval defaults to the one saved on SCR-14.
  4. Start from: in M9 every run starts from its lineage's base (ADR-0015); the page says whether that base exists or will be created. Choosing a trained version to start from is not offered yet.
  5. Device is Auto, GPU or CPU, with what Auto will do for this model ("under 1 M parameters: times both and picks the faster") and whether a GPU job is running now (RUN-1.9).
  6. The VRAM check warns, it does not block. It adds weights, gradients, optimizer state and the activation estimate for the batch size, and compares the sum with the 5.1 GB cap. Over the cap it says so and offers the largest batch that fits by the estimate. Starting anyway is allowed: the estimate is rough, and a run that does run out of memory fails cleanly with a suggested batch (RUN-1.5).
  7. "Start again with 64" on a run that ran out of memory (SCR-07, SCR-04) opens this page prefilled with that run's settings and the suggested batch. This closes the difference accepted at their Gate 3.
  8. Errors from the server land on their fields: a 422 from POST /jobs marks each field it names; spec problems link back to SCR-08.
  9. The study part (M10) is a collapsed section, Tune with a study, marked as arriving in M10, so the layout has room for it now.
