SCR-04 — Live job view · hi-fi mockup v1

Gate 2, step 2 of 2

Built on the approved low-fi wireframe (SCR-04-lofi_v1.html, approved 2026-11-15) inside the approved SCR-01 shell, using only design system v1 tokens and components. Charts are drawn as static SVG here; the real screen uses ECharts with the same tokens (design system c, live chart). Open as SCR-04_v1.html#light to start in light.

Decisions made in this step, for review
  • The activity line is a card with a left edge in the job-state colour, so it reads as part of the state: blue while running, red on failure, green on completion.
  • Resource tiles are the design system's metric tile, each with a 46-px chart of the last 5 minutes in its resource colour. In the VRAM chart, NVML is the solid line and PyTorch's reserved memory the dashed one, the convention the design system set for MON-2.4.
  • Timeline segments are the design system's timeline bar; their colours are job-state colours, with an icon and the stage name in each, so state never rests on colour alone.
  • The failure panel reuses the error-state treatment (danger-soft background, danger edge) at the top of the page, where the activity line was.
  • No new icons; everything here is in the set.

Accessibility notes for implementation

  • The state pill is a role="status" region, announced once per change; a failure is role="alert". The activity line is polite and throttled to one announcement every 10 seconds; the log is role="log".
  • Resource numbers are not announced as they change. Each tile's accessible name gives its value, unit and 5-minute maximum, and each chart has a text alternative.
  • Timeline segments are buttons in a list; the selected one has aria-current and the focus ring.
  • The cancel dialog is an alertdialog; focus starts on "Keep running" and returns to "Cancel job" when it closes.
