Decisions to review (beyond the approved low-fi)
  • A categorical value is told apart by its alignment and its column, not by quotes: numbers right-aligned, text left-aligned, and the column's header says categorical · embedding under its name. After set_kind, magnesium moves to the left and its values are semibold, the mark for a cell an operation changed. Quotes, as in the low-fi, made every categorical cell noisier than the numbers around it.
  • Changed columns carry an accent underline in the preview's header and an accent outline in the schema chips; the change is always in words beside it too (renamed, categorical · embedding), so colour is never the only sign.
  • Each operation's effect line starts with an info icon in muted grey; a refused one's message is in danger red with a ✕ icon, and an all-cast_failed step gets the warning icon and a warning callout in the preview. The card's border follows: accent when focused, danger when refused.
  • Run carries a play icon and stays the only primary button on the page. When disabled it uses aria-disabled, so it keeps focus and reads its reason ("2 problems" or "Add an operation first"), as SCR-09's Turn on does.
  • The preview's freshness is a quiet "updated 0.2 s ago" at the right of its header; while the next preview is computing it reads "updating…" and the rows dim to 45 %, so nothing moves.
  • New composites (each from existing tokens): the operation card (SCR-09's card and select), the schema chip (SCR-09's chip), the Add operation menu (SCR-09 v2's native-list drawing), the ordinal order list (chips with arrow keys), and the native radio in accent (SCR-09 v2's kind cards).

Accessibility notes

  • Keyboard path. Tab order: Run's choices, Reset, Run; then each card (its op select, fields, ⋮ menu); Add operation; Later stages; the preview. Alt+↑ / Alt+↓ move the focused card; the ⋮ menu has Move up, Move down, Duplicate and Remove, so the grip is never the only way. The ordinal order moves with Alt+← / →.
  • Never colour alone: a refused card has its message and a ✕; a cast_failed cell has a ✕ and the reason column; changed columns say how in words; status reads accepted or rejected beside its dot.
  • Announcements. The preview's header line (counts and freshness) is aria-live="polite", so a screen reader hears "50 accepted, updated" after an edit; each refused field is aria-invalid with its message as its description.
  • Contrast uses the text tokens on --surface and --surface-raised, as approved; the danger text in light uses the same 85 % mix with text-primary as the approved badges. Measured at Gate 3 in both themes.
  • Motion: the dimming while a preview computes has no transition when prefers-reduced-motion is set; skeletons stop shimmering.
