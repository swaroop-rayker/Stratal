SCR-11 — Model registry · hi-fi mockup v1

Gate 2, step 2 of 2

Built on the approved low-fi wireframe (SCR-11-lofi_v1.html, approved 2026-11-17) inside the SCR-01 shell, using only design system v1 tokens and components, plus one proposed icon. Open as SCR-11_v1.html#light to start in light.

Decisions made in this step, for review
  • Version states use existing colours: trained is the completed colour with its check; partial is the paused colour with the pause icon, because a partial version is a paused run; base is a neutral outlined label with no state colour. The word always carries the meaning.
  • Disk use is one stacked bar in data-viz categorical 1–5 (base, latest, intermediate, pinned, checkpoints), with a legend of figures beneath; a check says the registry's total matches the bytes on disk (REG-2.11).
  • The deletion dialog follows the design system's rule for deleting data: besides listing the versions and sizes, it asks for the lineage's name to be typed (DESIGN-SYSTEM, destructive actions). The approved low-fi did not show this; it is added because the pattern requires it. Automatic retention after a run asks nothing, as REG-2.2 expects.
  • One new icon is proposed: a pin (outlined, filled when pinned), in the set's 16-px stroke style, for REG-2.5. No icon in the set says "pin".
  • "Try it" shows its device as plain text under the result; the "GPU busy" refusal is the alert icon, its code as an error badge, and the reason in secondary text, without a tinted panel inside the card (a tint on a tint failed contrast).

Accessibility notes for implementation

  • The pin is a toggle button named with its version ("Pin mv_…" / "Unpin mv_…"), with aria-pressed.
  • The disk-use bar is an image whose name lists the five parts; the figures beneath are the table view.
  • The deletion dialog focuses "Keep them"; the delete button is disabled, and says why, until the name matches.
  • "Try it" announces its result politely, including the device; the refusal is an alert.
