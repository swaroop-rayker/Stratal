SCR-11 — task metrics in the version drawer (EVAL-1.2) · hi-fi mockup v1

Gate 2, step 2 of 2

Built on the approved low-fi wireframe (SCR-11eval-lofi_v1.html, approved 2026-11-20) inside SCR-11's approved drawer, using only design system v1 tokens and components and no new icon. Everything else on SCR-11 keeps its approved look. Frames A, B and E use real versions from the live stack: the Small CNN from the HPO demo (mv_a4a0fb846812), the Tabular MLP on diabetes (mv_b46259218b0e) and the LSTM on the COCO captions, 78 classes (mv_2eb4cd656334). The k-means and PCA figures in C are illustrative: no such version is on the live stack. Open as SCR-11eval_v1.html#light to start in light.

Decisions made in this step, for review
  • The section is a card inside the drawer, on the surface colour with a border, as SCR-10's cards are; its title "Task metrics" with the task as a neutral badge, and the requirement ID at the right.
  • The metrics table uses the design system's dense table, figures right-aligned in mono with tabular numerals, three decimals for scores and thousands separators for counts. Loss and rows are secondary rows in muted text.
  • A study's single test evaluation is the accent computed once badge in the Test column's heading (SCR-10's colour for it), with one line naming the study.
  • Per-class F1 bars are categorical 1 with the figure printed, as SCR-10's importance bars. The Validation / Test toggle is the group-button control.
  • The confusion matrix shades each cell by its share of the row in categorical 1 mixed into the surface, so the diagonal stands out, and prints every count, so colour is never the only cue. The shade is capped at 45 % of categorical 1 so every count stays readable; a cell at half the row or more prints in bold. Hover or focus shows the sentence in a tooltip; Table swaps the grid for a plain table.
  • Above 20 classes the matrix is replaced by "Most confused" (frame E): true class, predicted class, the count and its share of the true class's rows.
  • No metrics (frame D): a short sentence in secondary text, and Re-train as a small secondary button where re-training would score it.

Accessibility notes for implementation

  • The metrics table has a caption and real headers; figures are text, never only a bar.
  • The confusion matrix is a grid with row and column headers; each cell's accessible name is its sentence ("cat predicted as dog: 94"), and arrow keys move between cells, showing the tooltip. Every cell prints its count, so the shading is never the only cue.
  • The per-class bars are hidden from screen readers; the figures beside them carry the values.
  • The Validation / Test toggles are pressed-button groups, as elsewhere.
