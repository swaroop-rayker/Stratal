SCR-11 — task metrics in the version drawer (EVAL-1.2) · low-fi wireframe v1

Gate 2, step 1 of 2Addendum to SCR-11 v1 (G2 approved 2026-11-17; G3 2026-11-19)Serves EVAL-1.2, EVAL-1.2.AC12026-11-20

EVAL-1.2's scores are computed for every run since M10 and stored on the version (metrics and metrics.detail), but SCR-11's drawer still says test: not evaluated. This wireframe draws where they go. Everything else on SCR-11 keeps its approved design. The figures in frames A and B are real (the k-means and PCA figures in C are illustrative; no such version is on the live stack): the Small CNN from the HPO demo (mv_a4a0fb846812), the Tabular MLP on diabetes (mv_b46259218b0e).

Decisions in this step, for review
  1. One section, "Task metrics", in the drawer, under the facts and above the config. It replaces the two rows val acc · loss and test not evaluated.
  2. The task's set comes from the server (metric_set(task)): the same table for every task, one row per metric, columns Validation and Test (or Train for clustering and PCA, which have no held-out split). The task is named as a badge.
  3. Detail by task, under the table: per-class F1 as bars and the confusion matrix for classification; nothing more for regression (the scores are on the target's own scale, said once); clusters and noise points for clustering; explained variance by component for PCA.
  4. The confusion matrix shows one split at a time (Validation / Test toggle), as counts, the diagonal darkest. Above 20 classes it is replaced by the ten most frequent confusions as a list, since a 78×78 grid does not fit a drawer.
  5. A test score from a study is marked computed once with a link to its study (SCR-10); a single run's test score is simply its test column.
  6. A version with no task metrics says why: a base (never trained), a run from before M10, or a partial run. A run from before M10 offers Re-train, which scores it.
  7. The versions table is unchanged (its val acc column stays). Putting a test column in the table is left for SCR-11 v2's comparison view.

Accessibility notes

  • The table is a real table with a caption; the per-class bars are hidden from screen readers when a table of the same numbers follows, or carry their figure as text.
  • The matrix cells are a grid with row and column headers; each cell's accessible name is its sentence ("cat predicted as dog: 94"). Colour depth is never the only cue: every cell prints its count.
  • The split toggle is a pressed-button group, as elsewhere.
