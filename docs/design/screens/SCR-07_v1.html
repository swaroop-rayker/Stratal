Decisions made in this step, for review
  • Everything is a reused component. State pills, the table, the pressed button group with counts (SCR-03), the danger button, the destructive confirm and the toast (SCR-04). No new icons.
  • Row actions are always visible on actionable rows rather than only on hover, so they are reachable without a mouse and nothing jumps when the pointer moves. Rows with no action show nothing in that column.
  • The "Now / outcome" column uses the error colour only for the failure's code, the running-state colour only for the progress bar; the rest is secondary text, so the State column stays the one place to read state.

Accessibility notes for implementation

  • The table is a grid; each row is one focusable unit (j/k, Enter opens). Row actions are real buttons inside the row, reached with Tab.
  • State changes in the list are announced politely once ("job_0145 failed"); the list itself is not a live region, so updating progress is not read out.
  • The state filter is a toggle group; each button's name includes its count ("Failed, 1 job").
