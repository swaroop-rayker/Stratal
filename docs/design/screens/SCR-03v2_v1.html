Built on the approved low-fi wireframe (SCR-03v2-lofi_v1.html, approved 2026-11-21 with both of its questions) inside SCR-03's approved look: its header, lineage nodes, status tiles, tabs and duplicate-group drawer, unchanged. Only design system v1 tokens and components, and icons already in the set. The data is real unless marked: coco10k's split ds_3f6fcc420a27 and its lineage, its two preprocess versions (ingest min_size 256 against 255), CIFAR-10's split ds_f8e67211dd94 and its 16 trained versions. Frame C's rows are illustrative (no label version has clusters yet); its counts are spike S-10's at 0.90 and its pair is S-10's real pair. Open as SCR-03v2_v1.html#light to start in light.

Decisions made in this step, for review
  • The new tabs sit in SCR-03's tab bar in the order Rows, Reasons, Distributions, Compare, Models, Config. Models carries a count and appears only on a version models train on.
  • The funnel is the dense table, one row per stage, this version's row in the selected-row look. What a stage removed is a set of reason chips: a pill with the status's dot (rejected danger, duplicate muted, filtered warning, as the tiles), the code and the rows. A chip is a button that opens Rows filtered to that reason. A split's parts are a mono line.
  • Histograms draw raw as an outline in text-secondary and here filled in categorical 1, on shared bins, with a key above and both counts printed at the right of each bin, so neither colour nor shape is the only cue. Every histogram card has a Table toggle.
  • The five-number tables are dense tables with figures right-aligned in mono. Here takes the selected-row look; removed is one muted line saying what the removed rows have in common.
  • Compare's header is a select of the dataset's versions with a ghost Swap. The config difference is an info callout, with each changed setting as name old → new. Counts are a two-column list with changed in semibold. Changed rows are a table of field, A and B, using the row status dots. Wording-only rows are folded into one muted line with Show.
  • The semantic-cluster tile joins the four status tiles as a fifth, its left border in categorical 1, because a cluster is not a status. The row chip is a mono tag on a categorical-1 tint. The drawer reuses the duplicate group's head and side-by-side cards, with no kept ring, since every member stays accepted.
  • The lineage strip ends with a dashed "→ 16 models" chip with the grid icon, after the last node, which opens the Models tab.
  • The Models tab is the dense table grouped by lineage (section rows with the lineage ID where names repeat). The metric reads "test 0.831" or "val 0.839", so the split is always named. Deleted weights are in secondary text. Compare on this test split and Train a model… sit under the table.
  • A pressed tile's secondary line is text-secondary, the existing rule for secondary text on a selected surface (SCR-02 G3): with text-muted it measured 4.50:1 in light, too close to the limit.

Accessibility notes for implementation

  • The funnel, five-number and Models tables have captions and headers; reason chips are buttons named by their reason and count.
  • A histogram is an image with a full text label, and its Table view lists the bins; both counts are printed beside every bin.
  • The semantic tile is a toggle button like the status tiles; the cluster chip's text carries the cluster, never its colour alone.
