Layout decisions to review

  1. One drawer, two steps, a step bar at the top (1 Data · 2 Kind), 480 px wide like Start pipeline. The footer holds Back, Cancel and one primary button that names where it goes: Next in step 1, then Open the builder → or Set up the run →.
  2. Step 1 is two selects and a facts box. Dataset, then version. The version select lists only the versions a model can train on, newest first, with row counts. Once chosen, the facts box shows type, task, input → output and the split sizes, so the person sees what step 2 will allow before going on.
  3. Correction to SCREENS.md v3, for your OK: v3 says the drawer lists split versions. Labelled text trains on a tokenize version, not on its split (the API says so for ds_29636e3f171b: "labelled text models train on a tokenize version"). So the version select lists split versions for images and tables and tokenize versions for text, and SCR-03's Train a model… is offered on those same stages. I have drawn it that way (frame D) and will correct the two sentences in SCREENS.md with this wireframe's approval.
  4. Step 2 is a radio list of the two kinds, each a card with its name, one line on what it is and one on where it leads. A kind the split does not allow is a dashed, greyed card that stays in the list, cannot be selected, and gives its reason in words (never colour alone). The arrow keys skip it.
  5. The default in step 2: the first allowed kind is selected; for a table that is Network, so nothing is preselected in a way that hides Classical. Both are equal cards, Network first because it is offered for every type.
  6. From SCR-03, step 1 folds into one line (cifar10 · ds_f8e67211dd94 · labelled images) with Change, and the drawer opens at step 2.
  7. SCR-09's Model card shows the chosen kind as a label, not the v2 segmented control, with Change… beside it. Change… opens the same drawer at step 2 over SCR-09. When a network spec would be left behind, step 2 shows a warning callout under the kinds as soon as Classical is selected, before the button is pressed.
  8. /runs/new without a kind renders SCR-09's header and an empty Model card behind the drawer, opened at step 2 (with a version) or step 1 (without). Closing the drawer leaves SCR-09's empty state, "Choose what to train first.", with Choose….
  9. States live inside the drawer: skeleton lines while the version and the types load; an error state with Retry that keeps step 1's choice; empty states that link to where data comes from.
  10. Keyboard path: the drawer traps focus; Tab goes dataset → version → Next; in step 2 the arrow keys move between allowed kinds, Enter presses the primary button, Esc closes and returns focus to the button that opened it.
