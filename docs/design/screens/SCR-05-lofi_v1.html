Layout and hierarchy only, inside the approved SCR-01 shell (faint). Blue numbers are annotations. The review is SCREENS.md flow 2: started from a labelled and filtered version on SCR-03, decided item by item here, closed into a summary that leads to the eval report.

Layout decisions to review

  1. One item at a time, image first. The image takes most of the width; the caption sits beside it in 16-px reading text, so the question "does this caption describe this picture?" can be answered at a glance.
  2. Keyboard first. a accept and r reject decide and move to the next undecided item; j/k move without deciding; n opens the note. The two decision buttons are large and show their keys, for mouse use and to teach the keys.
  3. Each decision is saved at once (one request per decision), so closing the tab loses nothing; the item strip shows what is saved.
  4. The CLIP score is shown against the filter threshold as a small scale, so a low-scoring caption that passed the filter is visible. The score informs, it does not decide.
  5. Closing asks for confirmation only when items are undecided, then shows the acceptance summary with the next step, Build the eval report. The confidence interval is computed in the report (EVAL-1.1), not here.
  6. The strip at the bottom shows every sampled item as a numbered cell: accepted, rejected or undecided, the current one outlined. Click jumps to it.
