Decisions made in this step, for review
  • Losses made visible without bending the axis. Each funnel row keeps its kept-rows bar on a true 0–10,000 scale, and adds a second bar for what that stage removed, on its own scale (largest loss = full width), in the row-status colour: rejected red, duplicate grey, filtered amber. This answers the weakness noted in the low-fi.
  • Histogram: one colour from the sequential palette for the kept bins; bins below the threshold in danger, over a danger-soft band; the threshold itself a dashed warning line, as on SCR-05.
  • Interval: a success-tinted range on a 0–100% axis with ticks at 0, 50 and 100, the point estimate as a solid bar.
  • Headline cards carry a left edge only where colour means something: kept (success), filter rate (warning). Acceptance stays neutral; its interval carries the colour.
  • One new icon (chart), for the Chart/Table switch with the existing grid icon.

Accessibility notes for implementation

  • Every chart has a text alternative: the Table view (the same numbers), plus a short aria-label summary on the chart itself.
  • The interval is also stated in words beside the drawing; the drawing is decorative for screen readers.
  • Colour is never alone: funnel rows are labelled ("−148 rejected"), histogram bins below the threshold are also named in the key and the sentence below the chart.
  • The building state is a role="status"; a failed build is an alert.
