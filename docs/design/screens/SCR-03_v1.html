Built on the approved low-fi wireframe (SCR-03-lofi_v1.html, approved 2026-11-15) inside the approved SCR-01 shell, using only design system v1 tokens and components. Image thumbnails are placeholders drawn from the data-viz tokens; the real screen shows the images. Open as SCR-03_v1.html#light to start in light.

Decisions made in this step, for review
  • Status tiles are cards with a 3-px left edge in the row-status colour (the rule approved with SCR-02), a label, the number in mono and one line of context. Pressed (filtering) uses the accent outline, the same as a selected row.
  • Row-status filters are a group of small buttons with a pressed state, since the design system has no chip component; Table / Grid is a second group. Both reuse the button component's existing look.
  • Lineage nodes are the design system's lineage node. Their left edge carries the state of the job that made the version (completed green; a running child dashed and blue); this version is the "selected" node.
  • In the duplicate drawer, the kept image has a success outline and a "kept" pill; the hex characters where the two pHashes differ are highlighted, so the distance can be read off the hashes.
  • Three icons are new (eye, report, grid), same grid and stroke.

Accessibility notes for implementation

  • Status tiles and filter buttons are toggle buttons (aria-pressed); their label includes the count ("Duplicate, 340 rows").
  • The lineage strip is a list of links in order; the current version has aria-current. The running child is announced as "running, will add a child version".
  • The row drawer is a dialog; j/k move the selection in the table behind it, and the drawer's title is announced on each move.
  • Disabled actions use aria-disabled (not disabled) so they stay focusable and their reason can be read.
