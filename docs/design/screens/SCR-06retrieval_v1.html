Gate 2, step 2 of 2

Serves LLM-2.2 and LLM-2.3 at /versions/:version_id/report?kind=retrieval. It follows the approved low-fi wireframe (SCR-06retrieval-lofi_v1.html, 2026-11-27), SCREENS.md v5 and ADR-0022 rules 8–11, inside the approved SCR-06 (its header, head tiles, panels and callouts reused unchanged) and SCR-14 (a schema-generated section). The figures are illustrative, as in the low-fi: the question set is not written yet; the questions and their labelled sections are real, and the histogram, the threshold table and the confirmation are computed from one set of counts, so they agree.

Decisions to review (beyond the approved low-fi)
  • The hit@k tiles are SCR-06's head tiles without a status edge: a share is not good or bad by itself, so no success or danger colour; the count is in the line under the share.
  • Answerable questions are categorical 1 (the data-viz palette's first colour), unanswerable a hatched outline in text-secondary, so the two read apart in colour and in pattern; the threshold is a dashed text-primary line with its value at the top.
  • The current threshold's row in the table is highlighted (accent-soft with the accent edge) and says current; every other row has a ghost Use button. The best hit@5 in Other index versions is semibold, never coloured.
  • The confirmation is the design system's modal, with the change in numbers against the current value ("2 fewer", "2 more") and Set to 0.60 as its primary button.
  • SCR-14's retrieval section uses the form fields as SCR-14's other sections do, the model name in mono under its label, and the report it came from as a link.

Accessibility notes

  • Charts have their tables: the histogram is an image with a label pointing to a text table of the bins (both groups' counts per bin) that follows it; the threshold table itself is the chart's main reading.
  • Never colour alone: answerable is filled and unanswerable hatched; the current threshold row says current; the best hit@5 is semibold.
  • Keyboard path: header actions, the other index versions (Enter opens one), the threshold table (each Use a button; the confirmation traps focus and returns it to the row), then the missed questions.
  • Contrast as the approved SCR-06 and SCR-14; checked by measurement before review.
