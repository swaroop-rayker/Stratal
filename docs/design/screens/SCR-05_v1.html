Decisions made in this step, for review
  • Accept and Reject are equal secondary buttons, large (48 px), each with its key. Neither is "primary": nudging the reviewer towards one answer would bias the sample. Their icons carry the row-status colours (accepted green, rejected red), and the chosen one fills with its soft colour.
  • Strip cells use the same colours plus an icon (check or cross), so a decision is never colour alone; the current cell has the focus ring; a decision not yet saved is dashed amber.
  • The CLIP scale shades the part below the filter threshold in danger-soft and marks the threshold with a warning-coloured tick; the item's score is a dot.
  • The session pill uses info for "open" and muted for "closed": they are session states, not job states, so job-state colours are not borrowed.
  • One new icon (note).

Accessibility notes for implementation

  • a, r, n, j, k work only while focus is not in the note field; inside it, Esc returns to the item. Every action is also a button.
  • After each decision, the new item's position and caption are announced politely ("Item 25 of 50: …"); a failed save is an alert.
  • Judging a caption against its image needs sight of the image; this is the one task here that assistive technology cannot fully support. Everything else (caption, scores, facts, decisions, progress) is text and fully readable. The image's accessible name is its row key.
  • Strip cells are options in a listbox, each named "Item 4, rejected"; colour is backed by the check or cross icon.
