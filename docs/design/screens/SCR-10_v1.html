SCR-10 — HPO results · hi-fi mockup v1

Gate 2, step 2 of 2

Built on the approved low-fi wireframe (SCR-10-lofi_v1.html, approved 2026-11-19) inside the SCR-01 shell, using only design system v1 tokens, components and patterns, with no new icon. The charts use the categorical colours 1 and 2, as SCR-04 v2's do. The data come from two studies. The first tunes the Small CNN's learning rate, batch size (64, 128, 256 or 2048) and weight decay on CIFAR-10 (ds_f8e67211dd94), 10 epochs per trial. The second tunes a random forest on breast cancer with 5-fold cross-validation. Durations use S-09's figure of about 19 s of start per deep-learning trial. Open as SCR-10_v1.html#light to start in light.

Decisions made in this step, for review
  • Trial states are pills with an icon and words, as job states are: complete (completed colour, check), pruned (cancelled colour, ban icon) followed by "at epoch 3 · median" in muted text, failed (failed colour, alert) followed by its code, and running (running colour, pulse). The best trial gets an accent badge, best, rather than a state of its own.
  • The history chart draws trials as categorical-1 dots and the best so far as a categorical-2 step line, the same pair SCR-04 v2 uses for train and val. A pruned trial is a hollow dot. A failed trial is a cross in the failed colour on the axis. A legend says all of this in words, and Table swaps the chart for a table.
  • Importance bars are categorical 1 with the share printed beside each one. The method and its caveat sit under the bars.
  • The test evaluation is a card of its own, with the badge computed once, large figures, and when and on what it was computed. It has no button.
  • The breadcrumb reads Models › Study st_…, with no "Studies" level, since there is no list of studies.
  • Cancel is the danger button, and it opens a confirmation that says what will be lost: the current trial, registration and the test.
  • Data correction since the low-fi wireframe: trial 8 fails as over_vram because it drew batch 2048, the case SCR-09 now warns about. The median pruner cannot prune before trial 6, since it waits for 5 finished trials. So trial 5 completes, and trial 7 is the first one pruned.

Accessibility notes

  • Trial states are never colour alone: each pill has an icon and a word, and pruned and failed rows say why in text.
  • Each chart has a text alternative and a Table view with the same numbers. The legend names every mark: hollow, cross, step line.
  • The trial count, the time used and the running row's value are announced politely (aria-live) when a trial ends, not at every epoch.
  • The table is keyboard-navigable: arrows move between rows, Enter opens the drawer, and Esc closes it and returns focus to the row.
  • Cancel is an alert dialog whose default focus is Keep running.
