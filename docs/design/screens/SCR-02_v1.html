Built on the approved low-fi wireframe (SCR-02-lofi_v1.html, approved 2026-11-15) inside the approved SCR-01 shell, using only design system v1 tokens and components. Data is realistic. The buttons at the top switch the page between dark and light and hide the annotations; frame A is also shown in light below it. Open as SCR-02_v1.html#light to start in light.

Decisions made in this step, for review
  • Row-status colours in the stacked bar: accepted success, rejected danger, duplicate text-muted, filtered warning. They are semantic colours, not job-state colours, which stay reserved for jobs. A key sits above the table, and the four numbers are always printed beside the bar, so colour is never the only carrier.
  • Source choice in the drawer uses Tabs ("A folder" / "An existing version"). The low-fi drew a segmented control, which the design system does not have; Tabs are its nearest component.
  • Stage checkboxes are native checkboxes in the accent colour (the design system says forms that are submitted use checkboxes, not toggles).
  • Five icons are new (plus, more, folder, copy, branch), on the same grid and stroke.
  • Layout, columns and widths are as approved.

Accessibility notes for implementation

  • The dataset list is a listbox with one selected option; the versions table is a grid where the row is the unit of focus and Enter opens it. Tab moves list → filter → table → row menu.
  • The stacked bar has a text alternative: "9,512 accepted, 148 rejected, 340 duplicate, 0 filtered". The pending row announces its progress politely at most every 10 seconds.
  • The drawer is a modal dialog: focus moves to its first field, is trapped inside, and returns to the button that opened it. Field errors are linked with aria-describedby; the summary is role="alert".
