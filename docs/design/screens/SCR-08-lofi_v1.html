Layout and hierarchy only, inside the approved shell (faint). Blue numbers are annotations. The data: the CIFAR-10 split ds_f8e67211dd94 (3×32×32 images, 10 classes), a small CNN being built, then a residual block. Everything shown is computed by POST /model-specs/validate on each edit, in plain Python, before anything trains.

Layout decisions to review

  1. Three columns and a footer: a layer palette on the left, the graph in the middle, the selected layer's form on the right; the parameter count, memory estimate and problems in a footer that is always visible.
  2. The two ends are drawn and locked (BUILD-1.3): an Input node showing the dataset's shape and an Output node showing the head, Linear → 10. Changing the dataset at the top rewrites both and revalidates everything below.
  3. The canvas is a graph (owner's decision: full graphs). Layers stack top to bottom with automatic layout; a skip connection is drawn by dragging from one node's output handle to a merge node (Add or Concat). Each node shows its type, its two or three key fields, its output shape and its parameter count.
  4. A list view does everything the canvas does, from the keyboard (accessibility rule): one row per layer in order, with an Inputs column for merges and buttons to add, move and remove.
  5. Problems are words, attached to nodes (BUILD-1.4, 1.6): a red badge on the node, the same sentence in the footer list, and clicking it selects the node. A node whose shape cannot be worked out shows "?" instead of a shape, and nothing downstream repeats the error.
  6. The form is generated from the layer's JSON Schema (UI-2.3): ranges, defaults and help text come from the server, so a new field needs no UI code. Inferred sizes (in_features, in_channels) are shown as "inferred: 3072" and can be overridden.
  7. The palette offers only what the dataset type accepts (DATA-5.5): layers of another family are greyed with the reason ("images take mlp or cnn models").
  8. Templates (BUILD-1.7): Load template replaces the graph (asking first if there are unsaved changes); Save as template asks a name and a description. Built-in templates cannot be overwritten.
  9. The draft survives a reload in the browser's session storage, per dataset version; it becomes durable only as a template or a run. Continue to training carries the spec to SCR-09 and is disabled while there are problems.
