Layout and hierarchy only, inside the approved SCR-01 shell (faint). Blue numbers are annotations. The four parts are the four EVAL-1.1 asks: rejection counts per stage, the CLIP score distribution, the filter rate, and manual-review acceptance with a 95% Wilson interval. The statistics are computed by the owner's report unit (API.md §5); this screen only shows them.

Layout decisions to review

  1. Three headline figures first: rows kept, filter rate, review acceptance with its interval. They answer "is this dataset usable?" before any chart.
  2. Rejections per stage as a funnel: one row per stage, from 10,000 raw rows to the 9,431 kept, each showing how many it removed and why. It reads in pipeline order, which is how the question is asked.
  3. The CLIP distribution as a histogram with the filter threshold drawn on it and the part below it marked; mean and median as text.
  4. The interval is drawn, not just printed: a range on a 0–100% axis with the point estimate, so a wide interval looks wide.
  5. Every chart has a Chart / Table switch (the accessibility rule: charts have a text alternative); the table holds the exact numbers.
  6. The report is a snapshot: it names the review it used and when it was built. If a newer closed review exists, a note offers to rebuild with it.
